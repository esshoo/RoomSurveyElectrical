# AutoCAD compatibility fixtures

These files were generated by the v1.9 `DXFExporter` public export paths and passed the built-in `DXFCompatibilityValidator` before being written.

Use them for a quick strict-reader check:

- `3E-v1.9-single.dxf`
- `3E-v1.9-combined.dxf`
- `3E-v1.9-layouts.dxf`

They contain test geometry only and no embedded project data.
