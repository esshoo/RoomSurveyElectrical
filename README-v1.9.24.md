# 3ERoomElectrical v1.9.24 — Build 45

هذا الإصدار يضيف الأساس المشترك لنظام **تحديث وتحرير المشروع** بدون تنفيذ أدوات الرسم أو إعادة المسح الجزئي نفسها بعد.

## نظام الإعدادات متعدد المستويات

أضيفت نماذج مستقلة لـ:

- إعدادات التطبيق الافتراضية.
- إعدادات المشروع.
- إعدادات الغرفة أو المسح.
- استثناءات العنصر الفردي.

ترتيب الوراثة هو: التطبيق ← المشروع ← الغرفة/المسح ← العنصر. القيم القديمة تُرحّل تلقائيًا كإعدادات مشروع حتى لا يتغير سلوك مشروع موجود بعد التحديث.

## طبقات المشروع

أضيفت طبقات دائمة للمسح الأصلي، التصحيحات المعمارية، الكهرباء الموجودة والمقترحة، إضاءة السقف، الصور والخامات، الفرش والتصميم، والأبعاد والملاحظات. لكل طبقة حالة ظهور وقفل وشفافية محفوظة داخل المشروع.

## سجل التعديلات

أضيف إطار عام لجلسات التعديل يدعم مستقبلًا الإضافة والتعديل والحذف والاستبدال وتأكيد الوجود ووضع العنصر كغير موجود أثناء المراجعة. كل جلسة تنشئ نقطة استعادة قبل بدايتها.

## نقاط الاستعادة

- إنشاء نقطة يدوية.
- نقطة تلقائية قبل جلسة تعديل.
- استعادة نقطة سابقة بعد إنشاء نقطة أمان للحالة الحالية.
- الاحتفاظ افتراضيًا بآخر 12 نقطة، مع حماية النقاط المرتبطة بجلسات نشطة.
- التراجع عن أحدث جلسة نشطة أو معتمدة باستخدام نقطة البداية المرتبطة بها.

نقطة الاستعادة تحفظ حالة مساحة العمل وملفات بيانات `RoomProject` لكل المسحات المرتبطة. الملفات الثقيلة غير القابلة للتغيير مثل الصور وUSDZ وARWorldMap تبقى في مجلدات المسح، وستستخدم العمليات الخطرة اللاحقة أسماء جديدة بنظام copy-on-write قبل الاستبدال. عند تصدير ملف `.3eroom` يُحفظ سجل الجلسات والإعدادات المحمولة، بينما تُحذف روابط وبيانات نقاط الاستعادة المحلية من الحزمة في Build 45.

## مركز تحديث المشروع

أضيف داخل صفحة المشروع الرئيسية ويعرض:

- أوضاع المشروع والمراحل التي ستنفذ فيها أدواتها.
- مصدر الإعدادات: موروث أو مخصص.
- طبقات المشروع وقفلها.
- حالة `ARWorldMap` لكل مسح.
- سجل جلسات التعديل.
- نقاط الاستعادة.

## التوافق

بنية `SurveyProject` القديمة تظل بصيغة الملف الحالية، والحقول الجديدة اختيارية. عند الفتح يتم إنشاء بنية Build 45 تلقائيًا بدون حذف المسحات أو الصور أو الكهرباء أو تغيير العرض الحالي.

## Build 45-HF1 — تصحيح اتجاه صور الحوائط

أضيف تصحيح اتجاه لكل حائط بقلب أفقي ورأسي محفوظين داخل `WallAppearance`. التصحيح الأفقي مفعّل افتراضيًا لمعالجة انعكاس اليمين واليسار المبلغ عنه، ويمكن إلغاؤه أو إضافة قلب رأسي من شاشة صورة الحائط قبل الانتقال إلى 2D أو 3D. التحويل يربط إحداثيات RoomPlan بالصورة ولا يغيّر ملف الصورة أو هندسة المسح، ويُستخدم كذلك في 2D و3D وتصدير GLB.
