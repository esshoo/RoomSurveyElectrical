# 3ERoomElectrical v1.9.25 — Build 46.1

هذا الإصدار يبدأ التنفيذ الفعلي لمرحلة الإيقاف والاستكمال وإعادة التموضع.

## ما الجديد

- زر **إيقاف مؤقت وحفظ** أثناء مسح RoomPlan.
- حفظ تلقائي للجزء الحالي عند مغادرة التطبيق للواجهة النشطة.
- مهلة خلفية من iOS لإكمال معالجة RoomPlan وحفظ المشروع.
- حفظ سبب الإيقاف ووقته داخل كل مسح بصورة متوافقة مع المشاريع القديمة.
- إظهار تنبيه أعلى المسح عند وجود جلسة متوقفة قابلة للاستكمال.
- تشغيل Relocalization قبل استكمال RoomPlan.
- عند فشل التعرف على المكان لا يُحذف الجزء المحفوظ، ويمكن إعادة المحاولة أو اعتماده كما هو.
- ربط الإيقاف الحراري بنفس نظام الاستكمال المحفوظ.

## ما لم يدخل بعد

- نقاط الحفظ الدورية القابلة للضبط: Build 46.2.
- إعادة تصوير الأجزاء الضعيفة وإعادة بناء صورة الحائط: Build 46.3.

## الاختبار المطلوب على iPhone

اختبر الإيقاف اليدوي، والخروج للتطبيقات الأخرى، ونجاح وفشل إعادة التموضع، والإيقاف الحراري، ثم تأكد أن إنهاء المسح بعد استكماله يزيل علامة المسح المتوقف.
