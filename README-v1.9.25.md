# 3ERoomElectrical v1.9.25 — Build 46.1 + HF1 + HF2 + HF3

هذا الإصدار يبدأ التنفيذ الفعلي لمرحلة الإيقاف والاستكمال وإعادة التموضع، ثم يضيف إصلاح التعرف الهجين على آخر حائط.

## Build 46.1

- زر **إيقاف مؤقت وحفظ** أثناء مسح RoomPlan.
- حفظ تلقائي للجزء الحالي عند مغادرة التطبيق للواجهة النشطة.
- مهلة خلفية من iOS لإكمال معالجة RoomPlan وحفظ المشروع.
- حفظ سبب الإيقاف ووقته داخل كل مسح بصورة متوافقة مع المشاريع القديمة.
- إظهار تنبيه أعلى المسح عند وجود جلسة متوقفة قابلة للاستكمال.
- إعادة المحاولة أو اعتماد الجزء المحفوظ دون حذفه عند فشل الاستكمال.
- ربط الإيقاف الحراري بنفس حالة الاستكمال.

## Build 46.1-HF1 — التعرف الهجين

- الاحتفاظ بآخر ARWorldMap جيدة بدل الاعتماد على خريطة ضعيفة لحظة الإيقاف.
- حفظ Anchor عند آخر حائط تم مسحه.
- حفظ صورة وأبعاد وموضع واتجاه آخر حائط ظاهر أمام الكاميرا.
- مقارنة الحائط المكتشف بالعرض والارتفاع والمركز واتجاه المستوى، وليس بالأبعاد وحدها.
- عرض الصورة المرجعية ورسائل تقدم تفصيلية أثناء إعادة التموضع.
- إضافة إذن موقع عند الاستخدام ومساعدة اختيارية بالموقع التقريبي واتجاه البوصلة.
- رفض الإذن أو ضعف الموقع لا يمنع استخدام AR والحائط.
- ثلاثة مستويات للتعرف: صارم، متوازن، مرن.
- البيانات الجغرافية والصورة المرجعية محلية ولا تدخل في حزمة المشروع المحمولة.

## Build 46.1-HF2 — إصلاح تجميع Xcode

- إضافة إرجاع صريح لقيم `SpatialWorldMapQuality` داخل `worldMapQuality(for:)`.
- جعل callback فشل Core Location غير معزول لأنه لا يلمس حالة `MainActor`.
- لا تغيير في منطق الاستكمال أو بيانات المشروع.

## Build 46.1-HF3 — إصلاح إرجاع الاتجاه

- إضافة `return` صريح لكل فرع داخل `cardinalDirection(_:)`.
- لا تغيير في منطق التعرف أو بيانات المشروع أو اتجاهات البوصلة المحسوبة.

## ما لم يدخل بعد

- نقاط الحفظ الدورية القابلة للضبط: Build 46.2.
- إعادة تصوير الأجزاء الضعيفة وإعادة بناء صورة الحائط: Build 46.3.

## الاختبار المطلوب على iPhone

اختبر الاستكمال من آخر حائط في الأوضاع الثلاثة، مع قبول ورفض إذن الموقع، ومن نفس الحائط ثم من حائط مشابه مختلف، وتأكد أن إنهاء المسح يزيل حالة الاستكمال.
