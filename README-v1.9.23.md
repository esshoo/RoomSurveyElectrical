# 3ERoomElectrical v1.9.23 — Build 44

إضافة إعدادات الحماية الحرارية داخل **الإعدادات ← التطبيق ← المسح المكاني** مع الحفاظ على نظام الحفظ والاستكمال الموجود في Build 43.

## أوضاع الحماية

- **حماية مبكرة:** يسمح بالبدء عند الحالة الدافئة، لكنه يحفظ ويوقف المسح إذا استمرت الحالة 20 ثانية، ويحتاج عودة الحرارة إلى طبيعية قبل بدء مؤقت المتابعة.
- **متوازن — موصى به:** يستمر عند الحالة الدافئة، ويحفظ ويوقف عند الحالة المرتفعة أو الحرجة.
- **جلسة ممتدة:** يستمر عند الحالة المرتفعة، ويتوقف ويحفظ إلزاميًا عند الحالة الحرجة.

## الاستكمال

يمكن اختيار مدة استقرار الحرارة قبل تفعيل زر المتابعة: 15 أو 30 أو 60 ثانية. عند تغير الحالة أثناء العد يبدأ التحقق من جديد.

## العرض والأمان

- خيار لإظهار حالة الحرارة أثناء المسح.
- منع بدء الجلسة إذا كانت الحرارة أعلى من الحد المسموح للوضع المختار.
- الحفظ الوقائي قبل الإيقاف مفعّل دائمًا ولا يمكن تعطيله.
- الإعداد يعتمد حالات iOS المعايرة لكل جهاز، وليس درجة حرارة ثابتة بالسيلسيوس.

## التوافق

الإعدادات الجديدة اختيارية داخل JSON؛ المشاريع والإعدادات القديمة تستخدم تلقائيًا: **متوازن + 30 ثانية + إظهار الحالة**.
