# 3ERoomElectrical v1.9.19 — Build 40

This build adds an independent wall-photo/colour layer to the 2D plan.

- Photos and solid colours appear as aligned wall ribbons in 2D.
- Furniture, openings, electrical symbols, ceiling lights, dimensions, and highlights remain above the image layer.
- Existing per-wall opacity is respected.
- The existing layer menu controls photos in both 2D and 3D.
- The Photos tab can navigate to a wall in 2D or 3D.
- No changes to RoomPlan capture, photographic scanning, electrical logic, DXF, PDF, PNG, or GLB export.
