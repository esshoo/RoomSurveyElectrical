# 3ERoomElectrical v1.9.22 — Build 43

إدارة آمنة للمسح عند ارتفاع حرارة الجهاز، حفظ نتيجة المسح قبل إيقاف الكاميرا، استكمال مشروع موجود بعد إعادة التعرّف على المكان، إعادة المسح كنسخة مستقلة، وفتح جلسة التصوير فعليًا لإعادة تصوير أجزاء الحائط الضعيفة فقط.

## أهم التغييرات

- مراقبة `ProcessInfo.thermalState` أثناء RoomPlan.
- عند الوصول إلى Serious أو Critical يوقف التطبيق RoomPlan تلقائيًا، يطلب النتيجة الحالية، يحفظ المشروع وخريطة AR، ثم يوقف الكاميرا وينتظر تبريد الهاتف.
- بعد انخفاض الحرارة يمكن متابعة المسح من نفس المكان أو اعتماد الجزء المحفوظ والانتقال إلى الكهرباء.
- حفظ `ARWorldMap` للمسحات الجديدة داخل مجلد المشروع وحزمة `.3eroom`.
- خيار داخل المشروع لاستكمال المسح أو إضافة جزء جديد بعد Relocalization.
- خيار إعادة المسح كنسخة جديدة مع بقاء النسخة الأصلية كما هي.
- دمج هندسي محافظ يحافظ على معرفات الحوائط القديمة وروابط الكهرباء والصور قدر الإمكان.
- زر إعادة تصوير الأجزاء الضعيفة يفتح جلسة تصوير بعد التعرف على مكان المسح، ويعرض الأجزاء المحددة فقط.

## التوافق

- المشاريع القديمة تفتح طبيعيًا.
- الاستكمال الدقيق وإعادة تصوير جزء قديم يحتاجان خريطة AR محفوظة؛ لذلك يتاحان للمسحات التي تم إنشاؤها أو حفظها ابتداءً من Build 43.
- المشاريع القديمة يمكن إعادة مسحها كنسخة جديدة أو استخدام الصور المحلية.

## ملاحظة هندسية

المسح الإضافي يحدّث نموذج التطبيق الهندسي وروابطه، لكنه لا يعيد بناء ملف RoomPlan الأصلي `room.usdz` من عدة جلسات داخل هذا الإصدار. تصدير GLB ومخططات التطبيق يعتمد على بيانات المشروع المدمجة.
