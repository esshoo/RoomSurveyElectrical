# 3ERoomElectrical v1.9.13 — Build 31

## Interactive takeoff details

- Architectural takeoff now shows floor, ceiling, wall, opening and furniture dimensions.
- Electrical takeoff groups open a detailed list for every socket, switch, wall light, low-current outlet and air-conditioning point.
- Every electrical point shows its actual height, standard height, wall number, distance from the wall start and measured door offset when available.
- Ceiling lighting is separated into camera As-Built, manual 2D and automatic 2D groups, with height, diameter and brightness for every light.
- Tapping an individual electrical point or ceiling light opens a read-only 2D plan, centres the element and pulses it until the user touches the plan.
- The focused plan keeps the existing layer controls and does not expose editing tools.

## Safety scope

This build does not change:

- As-Built, Shop Drawing or new-installation placement rules.
- Electrical point creation, merging or opening avoidance.
- Camera ceiling-light placement.
- Manual or automatic 2D ceiling-light placement.
- DXF, PDF, PNG, GLB or project package exporters.
- Widget code or signing configuration.
