# 3ERoomElectrical v1.9.8 — Build 26

## Changes

- Restored the final dynamic WidgetKit extension for recent projects.
- Shares the six most recently updated active projects through App Group `group.com.essam.threeroomelectrical`.
- Shows cached 3D project previews when available, with project-type fallback artwork.
- Supports small, medium, and large Home Screen widgets.
- Each project entry deep-links into the matching project in the app.
- Added an always-visible close button to the full-screen PDF viewer.
- DXF export and DXF viewer sources are unchanged from v1.9.7.

## Signing requirement

The app and widget extension must each be signed with a compatible provisioning profile containing the same App Group. The source is complete even when an unsigned or basic sideloaded build cannot register the widget.
