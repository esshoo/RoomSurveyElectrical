# 3ERoomElectrical v1.9.26 — Build 47.2

## الهدف

ربط التطبيق الحالي بمجموعة تطبيقات 3E من دون إعادة بناء المشروع أو تغيير صيغة مشاريع الغرف والكهرباء. يعتمد الربط الحالي على مجلد `3E` يختاره المستخدم من تطبيق Files، ويحتفظ التطبيق بصلاحيته عبر Security-Scoped Bookmark.

## هوية التطبيق

- Display Name: `3ERoomElectrical`
- Bundle Identifier: `com.essam.3E.roomelectrical`
- App Key: `roomElectrical`
- URL Scheme: `electrical`
- App Folder: `Apps/RoomElectrical`
- Future App Group: `group.com.essam.3e`

## ملاحظة تغيير Bundle Identifier

الهوية السابقة في المشروع كانت `com.essam.threeroomelectrical`. تغييرها إلى `com.essam.3E.roomelectrical` يجعل iOS يتعامل مع النسخة الجديدة كتطبيق منفصل، ولا يسمح لها بقراءة Sandbox النسخة القديمة تلقائيًا. لا يحذف هذا الإصدار بيانات التطبيق القديم. قبل حذف النسخة القديمة يجب تصدير المشروعات كملفات `.3eroom` أو نسخها من Files إلى مجلد `3E` المشترك ثم استيرادها في النسخة الجديدة. النسخ التلقائي missing-only يعمل فقط للبيانات القديمة المتاحة داخل Sandbox التطبيق الجاري نفسه.

## ترتيب مصدر التخزين

1. App Group المستقبلية عند توفر Entitlement صالح.
2. مجلد `3E` الذي اختاره المستخدم من Files.
3. مساحة التطبيق الحالية كحل مؤقت فقط.

لا تحتوي نسخة التوقيع المجاني على App Group Entitlement. يبقى المعرف في الكود فقط استعدادًا للتوقيع المدفوع مستقبلًا.

## registry.json

يقرأ التطبيق `System/registry.json` قبل التعديل، ويحافظ على الحقول غير المعروفة وسجلات التطبيقات الأخرى. ثم يضيف أو يحدث سجل `roomElectrical` فقط، ويكتب النتيجة ذريًا. عند عدم وجود الملف ينشئ:

```json
{
  "schemaVersion": 1,
  "apps": []
}
```

ثم يضيف بيانات التطبيق المحددة.

## الروابط العميقة

يدعم التطبيق:

- `electrical://open`
- `electrical://open?path=Shared/Projects/ProjectName`
- `electrical://open?path=Apps/RoomElectrical/Projects/ProjectName`
- `electrical://open?project=<UUID>` لاستخدام الويدجت والتوافق الداخلي.

يُرفض أي مسار مطلق أو يحتوي على `..` أو `.` أو مكونات فارغة أو شرطة مائلة عكسية أو بادئة منزلية أو صيغة محرك، كما يتحقق التطبيق من المسار بعد حل الروابط الرمزية لمنع الخروج من جذر `3E`.

يظل URL Scheme القديم `3eroomelectrical` مسجلًا مؤقتًا للتوافق مع الروابط السابقة، لكنه ليس هوية الربط الجديدة.
