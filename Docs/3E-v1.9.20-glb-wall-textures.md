# 3E v1.9.20 — GLB Wall Textures

## Export controls

The GLB section contains two independent options:

1. Include wall photos and colours.
2. Include furniture.

## Embedded textures

Selected wall images are downsampled to a maximum dimension of 2048 pixels and encoded as JPEG at export time. The JPEG bytes are embedded in the GLB BIN chunk and referenced through glTF buffer views, images, textures, and PBR materials. No external texture folder is required.

## Wall geometry

Each customised wall receives a front overlay mesh in wall-local coordinates. Texture coordinates cover the full wall. The overlay is subdivided around detected doors, windows, and openings so the visual layer does not cover those regions. All appearance meshes are children of a `Wall Photos and Colors` node with a `wall-photos` layer marker in `extras`.

## Preserved model content

Electrical points, ceiling lighting, architectural openings, and optional furniture remain separate nodes. Project source images and existing exports are not changed.
