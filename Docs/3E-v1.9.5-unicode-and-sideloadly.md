# 3ERoomElectrical v1.9.5 — Unicode DXF and Sideloadly widget identity test

- DXF remains pure Model Space with no LAYOUT, VIEWPORT, OBJECTS, group 67, or group 410.
- DXF version is AutoCAD 2007 (`AC1021`) and string storage is UTF-8. Arabic is written as real Unicode.
- The in-app viewer also decodes legacy `\U+XXXX` strings from older DXF exports.
- Host bundle ID: `com.essam.threeroomelectrical`.
- Widget bundle ID: `com.essam.threeroomelectrical.widget`.
- In Sideloadly, disable **Use automatic bundle ID** and use the exact host bundle ID above. This test isolates bundle-ID mangling from WidgetKit registration.
- The widget is static and requests no App Group or custom entitlement.
