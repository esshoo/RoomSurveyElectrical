# 3ERoomElectrical v1.9.16 — Adaptive photographic scan V2

Base: v1.9.14 Build 32.

The rejected fixed-order scan was replaced by camera-driven segment selection. The coordinator evaluates all uncaptured wall segments on every throttled display tick and activates the best visible candidate using visibility, projected area, frontal angle and distance from the screen centre. A sticky score margin prevents rapid switching between adjacent candidates.

Automatic capture requires normal AR tracking, complete safe-area framing, sufficient projected dimensions, frontal alignment and 0.8 seconds of device stability. The active segment exposes progress at its projected screen position. When no candidate is visible, the nearest remaining in-front segment produces an edge direction pulse.

Each corrected segment JPEG is stored independently. `WallPhotoCompositeBuilder` tiles all captured segment images into a wall-aspect composite and makes that composite the primary captured-photo appearance. Existing SceneKit wall overlays therefore display the partial or complete result in 3D while electrical and lighting nodes remain in front.
