# 3ERoomElectrical v1.9.17 — Photo Furniture & Scan Performance

## Wall-photo furniture option

The Photos tab now contains a project-level option named **Show RoomPlan furniture over wall photos**.

- Enabled: detected furniture silhouettes remain visible in the wall-photo previews and furniture geometry remains visible in the 3D viewer.
- Disabled: furniture geometry is hidden while captured wall photos are displayed in 3D, preventing duplicated furniture when it is already visible in the photograph.
- Openings, electrical points, and ceiling-light additions remain above the visual wall layer.

The setting is stored in `WallPhotographicScanProgress` as an optional value, so older projects decode with the previous behaviour enabled.

## Spatial-scan screen setting

The App settings tab includes **Keep screen awake during spatial scan**.

`UIApplication.shared.isIdleTimerDisabled` is enabled only while RoomPlan is actively scanning and is reset during processing, cancellation, navigation away, and after completion.

## Performance changes

- The photographic AR overlay renders at 30 FPS without multisample antialiasing or automatic SceneKit lighting.
- Raw RoomPlan capture data is released immediately after the processed project is saved, reducing retained memory before the electrical/photo stages.
- Segment evaluation is reduced to 8 Hz under normal thermal conditions and is throttled further as the device thermal state rises.
- Core Image reuses one GPU-backed `CIContext` instead of constructing a new context for every capture.
- Wall composites are rebuilt when a wall is complete or when the user finishes the photo scan, instead of after every segment.
- Duplicate project saves from the photographic scanner were removed.
- Internal `project.json` saves use compact JSON; diagnostic RoomPlan JSON remains formatted.
- Wall images and thumbnails use bounded `NSCache` caches to reduce repeated file decoding.
- Display wall composites are limited to 2048 pixels on the longest edge; original segment photographs remain stored separately.
- The static 3D viewer renders on demand at 30 FPS with 2× antialiasing instead of continuously at 4×.
