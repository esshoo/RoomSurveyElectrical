# 3ERoomElectrical v1.9.26 — Build 48

## المشكلة

كانت نسخة Build 47.2 تتوقع أن يكون `apps` داخل `System/registry.json` قائمة فقط، بينما أنشأ 3ELocal السجل ككائن مفهرس بمفتاح كل تطبيق. أدى ذلك إلى رفض ربط مجلد 3E.

## الإصلاح

- قبول `apps` كقائمة قديمة أو كائن مفهرس.
- تحويل القراءة داخليًا إلى قاموس بمفاتيح `lidar` و`roomElectrical` و`localWeb`.
- تحديث سجل `roomElectrical` فقط.
- الحفاظ على سجلات التطبيقات الأخرى والحقول غير المعروفة.
- الكتابة الذرية عبر `NSFileCoordinator`.
- حفظ الصيغة الموحدة ككائن مفهرس.

لا يلزم حذف `registry.json` أو إعادة إنشاء مجلد 3E.

- تم رفع `CURRENT_PROJECT_VERSION` إلى `48` للتثبيت كتحديث جديد.
