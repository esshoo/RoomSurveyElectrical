# 3ERoomElectrical v1.9.19 — Plan 2D Wall Photo Layer

## Scope

This release adds the saved wall appearance layer to the top-down 2D plan without changing the spatial scan, photographic capture, electrical placement rules, DXF, PDF, or GLB exporters.

## Behaviour

- Captured wall photos and solid wall colours are rendered as an oriented ribbon along each wall in the 2D plan.
- The ribbon is drawn above the floor and below furniture, wall outlines, openings, electrical points, ceiling lighting, dimensions, and highlights.
- The existing `WallAppearance.opacity` value controls the ribbon opacity.
- The existing viewer layer toggle `صور وألوان الجدران` controls the layer in both 2D and 3D.
- Thumbnails are used for the 2D drawing path to limit memory and decoding cost.
- The wall photo is aspect-filled and clipped rather than stretched.
- The Photos tab can open a selected wall in either 2D or 3D.
- Opening a wall in 2D centres the plan on that wall and shows a temporary pulsing wall highlight.

## Compatibility

No new stored model fields are required. Existing projects use their current wall appearance, primary photo, opacity, and layer data.
