# Build 47.1 acceptance checklist

## Build 46 safe closure

- [x] الاستكمال داخل الجلسة الحية لم يُحذف.
- [x] فتح مسح متوقف بعد الخروج يبدأ مسحًا مستقلًا بدل الدمج التلقائي.
- [x] المسح المستقل يحمل مرجع المسح المصدر وحالة «يحتاج محاذاة».
- [x] قائمة المسحات تعرض حالة المحاذاة بوضوح.
- [x] بيانات المسح الأصلي لا تتغير عند إنشاء الجزء المستقل.

## Electrical review sessions

- [x] الجلسة مرتبطة بمسح واحد من البداية.
- [x] Recovery Snapshot تُنشأ قبل بدء الجلسة.
- [x] المسودة لا تعدل RoomProject.
- [x] إضافة وتعديل واستبدال وتأكيد وجود وتعليم غير موجود وحذف مدعومة.
- [x] يمكن إلغاء تغيير منفرد أو الجلسة كاملة.
- [x] الاعتماد يطبق التغييرات على المسح المستهدف فقط.
- [x] التطبيق يرفض السجلات القديمة إذا تغير العنصر خارج الجلسة.
- [x] سجل الجلسة يحفظ الحالة السابقة والجديدة.
- [x] التراجع العام عن Change Set يظل مرتبطًا بنقطة الاستعادة.
- [x] أوضاع As-Built وNew Installation وShop Drawing محفوظة في الجلسة.

## Device validation still required

- [ ] Full Xcode compile and unsigned IPA workflow.
- [ ] إنشاء جلسة على مشروع قديم ثم إلغاءها والتأكد أن العناصر لم تتغير.
- [ ] تطبيق إضافة وتعديل وحذف في جلسة واحدة ثم إعادة فتح التطبيق.
- [ ] التراجع عن الجلسة والتأكد من عودة جميع العناصر.
- [ ] إنشاء جزء مسح مستقل والتأكد أنه لا يظهر فوق المسح الأصلي كأنه محاذٍ.

## Build 47.2 — 3E shared-suite integration

- [x] هوية التطبيق الجديدة ثابتة في الكود وInfo.plist وBuild Settings.
- [x] لا توجد App Group Entitlement في التطبيق أو الويدجت أثناء التوقيع المجاني.
- [x] اختيار مجلد `3E` يتم عبر UIDocumentPickerViewController للمجلدات.
- [x] صلاحية المجلد تحفظ كـSecurity-Scoped Bookmark وتُستعاد تلقائيًا.
- [x] فشل الاستعادة يطلب إعادة اختيار المجلد ولا يعتبر Sandbox مجلدًا مشتركًا.

- [x] Shared وSystem والمجلدات الناقصة تُنشأ دون حذف ملفات موجودة.
- [x] registry.json يُقرأ ويُدمج ويُكتب ذريًا مع الحفاظ على التطبيقات الأخرى.
- [x] `electrical://open` والمسار النسبي وproject UUID مدعومة.
- [x] المسارات المطلقة و`..` والخروج عبر symlink مرفوضة.

- [ ] قبل حذف النسخة ذات Bundle ID القديم، تصدير مشروعاتها أو نسخها يدويًا إلى مجلد 3E لأن iOS يعزل الـSandbox بين الهويتين.
- [ ] اختبار اختيار المجلد نفسه المستخدم في 3ELiDAR و3ELocal على جهاز فعلي.
- [ ] إغلاق التطبيق وفتحه والتأكد من استعادة الـBookmark.
