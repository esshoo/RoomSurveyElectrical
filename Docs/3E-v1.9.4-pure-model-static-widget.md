# 3ERoomElectrical v1.9.4 — Pure Model DXF and static widget test

This build deliberately removes two variables from testing.

## DXF

The exporter writes AutoCAD R12 ASCII DXF (`AC1009`) with only:

1. HEADER
2. TABLES
3. BLOCKS (empty)
4. ENTITIES
5. EOF

No layout or paper-space records are emitted. Non-ASCII labels are serialized as DXF Unicode escape sequences so the file remains ASCII-safe.

## Widget

The WidgetKit extension shows static content and requests no App Group or custom entitlement. If it is absent from the iPhone widget gallery after this build is sideloaded with “Dropping 0 of 1 plug-ins”, the remaining failure is in extension provisioning/registration during sideloading rather than project-data sharing.
