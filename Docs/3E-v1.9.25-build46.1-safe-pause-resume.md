# v1.9.25 — Build 46.1 Safe Pause, Resume, and Relocalization

Build 46.1 establishes the first operational part of Build 46. It turns spatial scanning from a finish-or-lose workflow into a resumable workflow without modifying the original RoomPlan data directly.

## Safe pause and save

During a live RoomPlan scan the user can choose **إيقاف مؤقت وحفظ**. The capture session stops, the latest processed room or last live room snapshot is saved, and a usable ARWorldMap is preserved before the AR session is paused.

The same safe-save path is triggered when the application leaves the active foreground. A UIKit background task gives RoomPlan processing and project persistence additional time before iOS suspends the app.

## Persisted continuation state

`RoomProject` has an optional `scanContinuationState`. It stores:

- pause reason and date;
- last successful world-map capture date and quality;
- a reference anchor name;
- the last visible wall dimensions, transform, camera transform, and opening summary;
- a device-local reference image;
- optional coarse location and compass heading when permission is granted.

The field is optional, so projects created by earlier builds decode without migration failure. Completing or accepting a scan clears the continuation state and removes the device-local reference image.

## Resume and hybrid relocalization

A paused scan is highlighted in the room viewer. Opening it loads the saved ARWorldMap before RoomPlan is run again. Build 46.1-HF1 additionally asks the user to face the saved reference wall and validates:

- ARKit tracking recovery;
- restoration of the named anchor;
- detected wall width and height;
- wall center and plane orientation in the restored coordinate system;
- optional geographic and compass evidence according to the selected strictness.

The timeout is 90–120 seconds depending on strictness. A timeout no longer turns the scan into a terminal error. It pauses AR tracking and offers retry, accept the saved partial room, or return to the project.

## Privacy

Location is optional and uses a When-In-Use permission. Denial does not disable resume. Coordinates are rounded before local storage, and geographic evidence plus the reference image are stripped from portable `.3eroom` packages.

## Thermal integration

Thermal stops while scanning use the same persisted continuation state and saved world map. Thermal stops while relocalizing also record a thermal pause before entering the cooling screen.
