# 3ERoomElectrical v1.9.27 — Build 49.1

## الهدف

إضافة أول تنفيذ فعلي للتصحيح المعماري اليدوي مع عدم فقد نتيجة RoomPlan الأصلية وعدم تعديل المسح قبل اعتماد المستخدم.

## نموذج البيانات

أضيف إلى `RoomProject` حقلان اختياريان متوافقان مع المشاريع القديمة:

- `originalWalls`: نسخة غير قابلة للاستبدال من الحوائط قبل أول تصحيح.
- `architecturalCorrections`: سجلات التصحيح المعتمدة، وكل سجل يحتوي على Before/After وChange Set وscanID والمصدر والتاريخ.

يبقى `walls` هو الشكل الفعّال Materialized Geometry لضمان استمرار جميع العارضات والحصر والمصدرات الحالية في قراءة هندسة موحدة. عند الحفظ أو الفتح يُعاد بناؤه من `originalWalls + architecturalCorrections`، وليس العكس.

## سير العمل

1. يختار المستخدم مشروعًا ثم مسحًا محددًا.
2. يبدأ جلسة `architecturalUpdate` مرتبطة بـ`targetScanID`.
3. ينشئ النظام Recovery Snapshot تشمل Workspace وكل المسحات المرجعية.
4. يختار المستخدم حائطًا ويعدل العرض والارتفاع وX وZ وYaw.
5. يحفظ التعديل كـ`ProjectChangeRecord` في حالة Draft فقط.
6. يمكن رفض تعديل حائط بحذف سجله دون التأثير على المسح.
7. عند الاعتماد، يتحقق النظام أن الحائط الحالي يطابق Before State لمنع تطبيق تعديل قديم.
8. يضاف `ArchitecturalWallCorrection` إلى المسح، وتُعاد Materialization للهندسة.
9. تتحدث نقاط الكهرباء المرتبطة بنفس wallID مع الحفاظ على ارتفاعها الحقيقي من الأرض.
10. إذا فشل حفظ المسح أوWorkspace، يعاد المسح السابق.

## نظام الإحداثيات

- Right-handed وY-up.
- الواجهة العربية RTL، لكن مخطط Before/After يعمل LTR.
- لا يسمح Scale أوReflection داخل Transform.
- تعديل الحائط يستخدم Yaw فقط مع X/Z Translation.
- تغيير الارتفاع يحافظ على منسوب أسفل الحائط.

## التوافق

- الحقول الجديدة Optional، لذلك تفتح المشاريع القديمة دون Migration مدمرة.
- `foundationSchemaVersion` ارتفع إلى 3.
- النسخ والاستيراد يعيدان ربط `scanID` داخل التصحيحات بالمسح الجديد.
- ملفات DXF/PDF/GLB لم يتغير كودها في هذه الزيادة، لكنها تقرأ `walls` الفعالة بعد اعتماد التصحيح.

## الحدود

Build 49.1 لا يضيف فتحات جديدة أوSplit/Merge أوإعادة مسح جزئية. كما لا يعيد موضعة الأبواب والشبابيك والفتحات الموجودة عند نقل الحائط؛ يجب مراجعتها قبل الاعتماد إلى أن تُنفذ أدوات الفتحات في Build 49.2. هذه وظائف Build 49.2 إلى Build 49.4.
