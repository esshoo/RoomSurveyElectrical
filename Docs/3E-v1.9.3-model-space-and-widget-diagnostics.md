# 3ERoomElectrical v1.9.3 — Model Space only and widget diagnostics

## DXF

Paper Space export is disabled in this release. Every DXF path now writes real
graphical entities in Model Space only. The old `makeLayoutDXF` entry point is
kept as a compatibility alias, but it emits the same Model Space drawing as the
combined exporter.

Model entities omit group code 67 because the DXF default is Model Space. Group
410 is emitted only for genuine Paper Space entities; this release emits none.
The validator rejects any exported graphical entity carrying `67 = 1`.

## Home Screen widget

The WidgetKit target remains embedded in the application project. Its gallery
name is now `3ERoomElectrical` so it is searched under the same name as the app.

Widget visibility after sideloading depends on the *signed IPA*, not just the
Xcode source. Use:

```powershell
python .\Tools\inspect-signed-ipa.py "C:\Path\3ERoomElectrical-signed.ipa"
```

The inspector verifies that the nested `.appex` survived signing, has its own
signature and provisioning profile, uses the WidgetKit extension point, and is
a child bundle of the host application. It also reports whether both profiles
authorize the shared App Group required for recent-project data.
