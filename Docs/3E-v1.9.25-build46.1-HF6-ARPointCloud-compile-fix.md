# v1.9.25 Build 46.1-HF6 — ARPointCloud compile fix

## سبب الإصلاح

فشل Xcode في تجميع HF5 لأن `ARWorldMap.rawFeaturePoints` يعيد كائن `ARPointCloud`، وهذا النوع لا يملك خاصية `count` مباشرة.

## التصحيح

تم استبدال جميع استخدامات:

```swift
worldMap.rawFeaturePoints.count
```

بـ:

```swift
worldMap.rawFeaturePoints.points.count
```

وذلك في اختيار أفضل خريطة، وتسجيل تشخيص عدد نقاط الخريطة، وحفظ الخريطة الحالية.

## حدود التغيير

هذا إصلاح تجميعي فقط. لم يتغير منطق حفظ `ARWorldMap` أو إعادة التموضع أو درجات الصرامة أو دورة حياة `ARSession` و`RoomCaptureView`.
