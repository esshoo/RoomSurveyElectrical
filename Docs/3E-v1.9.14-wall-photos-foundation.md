# 3ERoomElectrical v1.9.14 — Wall Photos Foundation

## Release position

This is step 1 of 3. It establishes persistent wall identity, photo assets, appearance controls and a device-testable photos tab before automatic capture is introduced.

## Data compatibility

`RoomProject` adds optional `wallAppearances` and `wallPhotos` arrays. Old JSON files therefore continue to decode. Missing wall metadata is generated from the stable RoomPlan wall identifiers and saved when the project is next edited.

## Asset storage

Wall images are downsampled to a maximum 4096-pixel dimension and stored as JPEG beside the scan files. A separate thumbnail is generated for the UI. Assets use flat, safe names so existing package validation and import staging remain secure.

`.3eroom` archives containing wall-photo assets use package format version 2. Archives without wall photos remain version 1 for backward compatibility. The current reader accepts both versions.

## Rendering order

The wall photo/colour overlay is placed on the wall at a small local depth. RoomPlan openings are projected onto the wall and excluded from the generated quads. Electrical and manual-opening nodes remain in front of the visual overlay.

## Not included

- Automatic AR image capture.
- Adaptive patch generation for columns, protrusions and non-planar surfaces.
- Stitching or blending adjacent captures.
- 2D plan photo rendering.
- Textured GLB export.
