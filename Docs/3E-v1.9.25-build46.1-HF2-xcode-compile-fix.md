# v1.9.25 — Build 46.1-HF2 Xcode Compile Fix

هذا الإصلاح لا يغيّر منطق التعرف الهجين أو بيانات المشروع. وظيفته إغلاق أخطاء تجميع ظهرت في GitHub Actions بعد HF1.

## الأخطاء المصححة

1. `RoomCaptureModel.worldMapQuality(for:)`
   - كانت فروع `switch` تستخدم أعضاء enum مختصرة بدون `return` بعد وجود `guard` داخل الدالة.
   - أضيفت قيم الإرجاع الصريحة من النوع `SpatialWorldMapQuality` لكل حالة، بما فيها `@unknown default`.

2. `SpatialReferenceSensor.locationManager(_:didFailWithError:)`
   - الكلاس معزول على `MainActor`، بينما متطلب Core Location لهذا callback غير معزول.
   - تم تعريف callback كـ `nonisolated` لأنه لا يقرأ أو يغيّر أي حالة معزولة، ويظل فشل الموقع غير مانع لمسار AR والحائط.
