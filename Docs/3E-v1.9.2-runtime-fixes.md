# 3ERoomElectrical v1.9.2 runtime fixes

## DXF viewer exit

`DXFViewerScreen` now owns the presentation dismiss action and exposes an **إغلاق** button in the navigation toolbar. The viewer remains full screen, but it no longer traps the user inside the presentation.

## DXF Model Space and Layout structure

The layout exporter now follows these rules:

1. `*Model_Space` and paper-space block definitions in `BLOCKS` are empty containers.
2. Paper-space viewports and title text are written first in `ENTITIES` with group code `67 = 1` and the layout name in group code `410`.
3. Model-space geometry is written after paper-space entities with `67 = 0`, owner `*Model_Space`, and `410 = Model`.
4. Every `LAYOUT` object includes its persistent reactor group.
5. The compatibility validator rejects a file with no graphical Model Space entities, paper entities inside `BLOCKS`, or paper entities appearing after Model Space entities.

The normal combined DXF is shown first in the export UI and is labelled as the most compatible Model Space option. The advanced Layouts export remains available and still contains the full drawing in Model Space.

## Widget packaging and signing

The Xcode copy phase is now named **Embed App Extensions** and uses `CodeSignOnCopy`. GitHub Actions fails packaging when the built app does not contain:

```text
3ERoomElectrical.app/
└── PlugIns/
    └── 3ERoomElectricalWidgetExtension.appex
```

The workflow also verifies that the widget extension point is `com.apple.widgetkit-extension` and that the widget bundle identifier is the final main bundle identifier plus `.widget`.

Use the dependency-free validator on the final signed IPA:

```powershell
python .\Tools\validate-widget-ipa.py "C:\Path\3ERoomElectrical-signed.ipa"
```

This checks packaging and bundle identifiers. It cannot validate the cryptographic signature on Windows. The final signer must sign the main app and the nested `.appex` separately and provision the shared App Group for both identifiers.

The main screen now displays a diagnostic notice when the installed bundle is missing the `.appex` or the App Group container is unavailable.

## DXF verification on Windows

To check a file after export:

```powershell
python .\Tools\check-dxf-model-space.py "C:\Path\drawing.dxf"
```

A passing file reports a nonzero Model Space entity count and no paper-space entities inside `BLOCKS`.
