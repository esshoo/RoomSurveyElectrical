# Build 45 acceptance checklist

Build 45 is the shared foundation for later project-update tools. It does not claim to implement partial RoomPlan rescanning, element recognition, architectural drawing, floor alignment, furnishing, or QR sharing yet.

## Included

- [x] Optional migration-safe foundation fields on `SurveyProject`.
- [x] Four-level settings inheritance: app, project, room/scan, element.
- [x] Persistent project layer visibility, lock state, and opacity.
- [x] Generic change-set and change-record data model.
- [x] Manual and pre-operation recovery snapshots.
- [x] Recovery snapshots include workspace state and all referenced `RoomProject` JSON records.
- [x] Protected pruning for snapshots linked to active/applied change sets.
- [x] Project update/edit centre in the project interface.
- [x] App-level defaults for recovery retention and new-project layers.
- [x] ARWorldMap availability summary for each scan.
- [x] Package import preserves portable settings, layers, modes, and audit history.
- [x] Package export strips device-local recovery metadata and snapshot links.
- [x] Legacy projects normalise without changing their effective electrical/scan settings.

## Deferred by roadmap

- Build 46: actual pause/resume workflow, relocalisation UX, periodic live-scan checkpoints, and weak-photo recapture routing.
- Build 47: applying add/modify/delete/replace records to electrical and later element types.
- Build 48: architectural corrections and manual walls/openings/doors/windows.
- Build 49: multi-scan floor editor and alignment.
- Build 50: presentation scenes.
- Build 51: furnishing and realistic models.
- Build 52–53: project fingerprint, QR, web page, server, and cross-device permissions.

## Device validation still required

- Full Xcode compile and unsigned IPA workflow.
- Legacy-project migration on a real installation.
- Snapshot restore with projects containing images and ARWorldMap files.
- Layer lock/visibility behaviour in both 2D and 3D.
- Storage pruning under low-space conditions.
